# Lesson 03: Essential Formulas in Excel

This lesson covers the basic Excel formulas used to calculate totals, averages, percentages and simple results.

## What I Learned

- What an Excel formula is, and the difference between a formula and a function
- `SUM`, `AVERAGE`, `MAX` and `MIN`
- `COUNT` and `COUNTA`, and how they are different
- Calculating a percentage: `=G2/300*100`
- Showing Pass or Fail with a simple `IF` formula
- Relative references (`A1`) and absolute references (`$A$1`)
- Copying a formula to other rows with AutoFill

5. Try `COUNT` and `COUNTA` on a row that has a name and numbers.
