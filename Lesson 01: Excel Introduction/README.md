# Lesson 01: Excel Introduction

This is the first lesson of my Excel learning journey. It explains what Excel is, how the screen is laid out, and which keyboard shortcuts save the most time.

## What I Learned

- What Microsoft Excel is and what it is used for
- The difference between a workbook and a worksheet
- What a cell, a cell reference and a range are (for example `B3` and `A1:C5`)
- The difference between rows and columns
- The parts of the Excel screen: Title Bar, Quick Access Toolbar, Ribbon, Formula Bar, Name Box, Status Bar and Sheet Tabs
- What the Home, Insert and Data tabs are used for
- How to use the Fill Handle to copy data
- How to insert, rename and delete a sheet
- How to change the column width
- How to save a file, and the difference between Save and Save As
- How to add numbers with a simple `SUM` formula

## Practice

1. Open the practice file and click a Total cell to see its formula in the Formula Bar.
2. Select some marks and look at the Sum in the Status Bar.
3. Drag the Fill Handle to copy a formula down.
4. Change one mark and watch the Total update.
5. Rename the sheet, add a new one, then delete it.

## Most Useful Shortcuts

- Save: `Ctrl + S`
- Undo: `Ctrl + Z`
- Copy, Cut, Paste: `Ctrl + C`, `Ctrl + X`, `Ctrl + V`
- AutoSum: `Alt + =`
- Create a table: `Ctrl + T`

The full list is in the "Keyboard Shortcuts" sheet.
