# Lesson 02: Data Entry in Excel

This lesson explains how to enter, edit and manage data in Excel, and how to save time with AutoFill and AutoFit.

## What I Learned

- The types of data in Excel: text, numbers, dates, time, formulas and logical values
- How to enter and edit data in a cell (Enter, `F2` and the Formula Bar)
- The difference between Clear Contents and Delete Cells
- How AutoFill works, and how to create serial numbers from 1 to 100
- How to insert and delete rows and columns
- The difference between Copy, Cut and Paste
- How to use AutoFit to adjust column width
- How to keep leading zeros, such as `00125`

## Practice

1. Type text, numbers and dates in different cells and see how Excel aligns them.
2. Enter 1 and 2 in two cells, select both and drag the Fill Handle to create serial numbers.
3. Press `F2` to edit a cell, then try Clear Contents and Delete Cells.
4. Type `'00125` in a cell and check that the zeros stay.
5. Double-click a column border to AutoFit it.
